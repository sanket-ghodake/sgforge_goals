# Security Policy

The maintainers of this SG Forge Micro-App take security, zero-trust isolation, and tenant privacy seriously.

---

## 🔒 Reporting a Vulnerability

If you believe you have discovered a security vulnerability, please **do NOT report it through public GitHub issues or public discussions**.

Instead, send a responsible disclosure report via email:

* **Primary Security Contact**: `sanketghodke03@gmail.com`
* **Subject Format**: `[SECURITY VULNERABILITY] <Micro-App> - <Brief Description>`

Please include:
1. Affected component, route, or dependency.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. Potential impact (e.g. privilege escalation, cross-tenant data leak).
4. Proposed remediations.
