# Goals Micro-App - Utility & UI Library Layer (`src/lib/`)

Houses shared UI abstractions, Lucide vector icons, and TypeScript type definitions:

- `ui.ts`: Unified portable 4-library engine wrapper (**shadcn UI** + **Magic UI** + **Aceternity UI** + **Luxe**).
- `icons.ts`: 100% vector SVG icons (Lucide 1.75px stroke standard).
- `types.ts`: TypeScript data interfaces (GoalBoard, GoalItem, AuthUser, Reminder).
- `sdk.ts`: Monorepo SDK wrapper for authentication and logging.
- `docs-viewer.ts`: Embedded living documentation renderer.
