# Goals Micro-App - Source Directory (`src/`)

This directory houses the core application code for `@forge-apps/goals`, organized into clear tier boundaries:

- [`frontend/`](file:///home/sanket/Desktop/Sanket/org_website_clone/forge-apps/goals/src/frontend): SPA views, templates, and styling.
- [`backend/`](file:///home/sanket/Desktop/Sanket/org_website_clone/forge-apps/goals/src/backend): Domain services, state machines, and business logic.
- [`db/`](file:///home/sanket/Desktop/Sanket/org_website_clone/forge-apps/goals/src/db): Dedicated Turso libSQL ORM connection and schema definitions.
- [`lib/`](file:///home/sanket/Desktop/Sanket/org_website_clone/forge-apps/goals/src/lib): Shared portable 4-library UI engine, icons, and type definitions.
- [`server.ts`](file:///home/sanket/Desktop/Sanket/org_website_clone/forge-apps/goals/src/server.ts): HTTP dispatcher and server bootstrap entrypoint.
